# 🎮 PS2 Store

Uma loja de jogos clássicos de PlayStation 2 com interface moderna e responsiva.

## ✨ Recursos

- 🛍️ Catálogo completo de 18 jogos PS2
- 🔍 Busca em tempo real
- 📂 Filtro por categorias (Ação, Corrida, Futebol, Terror, Aventura)
- 🛒 Carrinho de compras funcional
- 📱 Design responsivo (Mobile-friendly)
- ⭐ Sistema de avaliações

---

## 🚀 Como ver o site

### Opção 1: Ver no GitHub (Recomendado para Preview Rápido)

1. Abra o repositório: [minha-loja](https://github.com/mj3105850-alt/minha-loja)
2. Clique no arquivo `index.html`
3. Clique no botão **"Raw"** ou **"Download"** para visualizar
4. Ou use o GitHub Pages (veja abaixo)

### Opção 2: Clonar o Repositório (Recomendado)

```bash
# Clone o repositório
git clone https://github.com/mj3105850-alt/minha-loja.git

# Entre na pasta
cd minha-loja

# Abra o arquivo no navegador
# Windows:
start index.html

# macOS:
open index.html

# Linux:
xdg-open index.html
```

### Opção 3: Servidor Local com Python

Se preferir usar um servidor local:

```bash
# Python 3.x
python -m http.server 8000

# Depois acesse: http://localhost:8000/index.html
```

### Opção 4: Servidor Local com Node.js

```bash
# Instale o http-server globalmente (primeira vez)
npm install -g http-server

# Execute na pasta do projeto
http-server

# Acesse: http://localhost:8080/index.html
```

### Opção 5: Live Server (VS Code)

1. Instale a extensão **Live Server** no VS Code
2. Clique com botão direito no `index.html`
3. Selecione **"Open with Live Server"**
4. A página abrirá automaticamente no navegador

## 📖 Como usar a loja

### 🔍 Buscar um jogo
1. Digite o nome do jogo na barra de pesquisa no topo
2. Os resultados aparecem em tempo real

### 📂 Filtrar por categoria
1. Clique em uma das categorias: Ação, Corrida, Futebol, Terror, Aventura
2. Clique em "Todos" para ver todos os jogos novamente

### 🛒 Adicionar ao carrinho
1. Clique no botão **"Adicionar ao carrinho"** em qualquer jogo
2. O contador do carrinho atualiza automaticamente

### 💳 Ver o carrinho
1. Clique no botão **"🛒 Carrinho"** no topo direito
2. Veja todos os itens e o total
3. Clique no **"✕"** para remover um item

### ✅ Finalizar pedido
1. Com itens no carrinho, clique em **"Finalizar pedido"**
2. Uma mensagem de confirmação aparecerá
